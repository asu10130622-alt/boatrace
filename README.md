# ボートレース検証ラボ

3連単の機械学習予想を、**当たりも外れも全部**公開する検証プロジェクト。

サイト: https://asu10130622-alt.github.io/boatrace/

## 何をしているか

ボートレースの3連単（払戻率75%）は、的中率を上げるだけでは勝てません。
「オッズが実力を反映していない場面を見つけて、それ以外を見送る」ことでしか
控除率25%を超えられない、という前提で検証しています。

- 締切前に全レースの予想を公開（後から都合よく編集できない）
- 結果は当たり外れに関わらずそのまま残す
- 直近5ヶ月・25,781レースの実測回収率を毎日更新

**いまのところ、まだ勝てていません。** 一番成績の良い買い方でも回収率91.9%
（100%が損益ゼロ）。それでも数字を隠さず出し続けます。

## 公開しているもの

このリポジトリは `docs/`（公開サイト本体）のみです。予測モデルのソースコード・
データ収集の仕組みは非公開です。
